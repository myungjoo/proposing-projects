== NNTrainer Project Proposal


*Name of project*: NNTrainer

*Requested project maturity level*: Sandbox stage

*Project description*:

NNTrainer is a software framework to train neural network models on embedded devices with limited computation resources.
Usually, but not necessarily, NNTrainer trains a pre-trained model for personalization; e.g., fine-tuning a base common model with additional data of a user.
However, it can still train a model from scratch as conventional frameworks do.


NNTrainer promotes easier and efficient development of on-device AI training for AI personalization with user data without the need for exposing user data out of the device.
NNTrainer provides highly efficient (both memory and computation) mechanisms as described in https://conf.researchr.org/details/icse-2024/icse-2024-software-engineering-in-practice/5/A-New-Frontier-of-AI-On-Device-AI-Training-and-Personalization[ICSE 2024 Paper].
NNTrainer is highly modular and extensible; thus, users can extend its functions with their own implementation, deployed as plugins.
With the given efficent computation mechanisms, users may also run large language models with more parameters on device; e.g., running 15 GiB LLM on an 8 GiB RAM device.


NNTrainer has started as an open source project since 2019 with Apache 2.0 license.
NNTrainer is released for Tizen, Ubuntu, and Android and tested daily for them.
It is applied to actual embedded devices: consumer eletronics including mobile phones (Samsung Galaxy S23 and later) run NNTrainer for on-device AI personalization.
https://www.zdnet.com/article/this-new-samsung-galaxy-feature-lets-you-clone-your-own-voice-sort-of/[ZDNet: This new Samsung Galaxy feature lets you clone your own voice (sort of)] is an example of NNTrainer applications.


NNTrainer is a spun-off project from another LF AI & Data project, https://nntrainer.ai[NNStreamer].

*Have you identified possible collaboration opportunities with current LF AI hosted projects (https://lfai.foundation/projects/)? Please explain.*:

 * ONNX: We have decided ONNX as the standard model format for the next version releases of NNTrainer. We will be highly depending on ONNX and its forward compatibility.
 * NNStreamer: NNStreamer and its other spun-off projects (Device MLOps and ML API) provide the standard interfaces and means to execute NNTrainer in many embedded devices. NNTrainer also provides a few plugins for NNStreamer.
 * JanusGraph: NNTrainer's new focus is on executing large language models (inferencing faster with less memory) and personalize them with given on-device user data, which will require on-device RAG and LoRA-generation. JanusGraph can be the graph database to store user data as knowledge graphs and provide RAG basis.
 * Milvus: This may provide knowledge graph and RAG basis as JanusGraph may do.
